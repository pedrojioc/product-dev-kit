# Engineering conventions (project)

## Stack
- Language / runtime: TypeScript, Node 22
- Test runner: vitest

## Commands
- Test: `pnpm test`
- Lint: `pnpm lint`
- Typecheck: `pnpm typecheck`

## Linear
- Workspace: `Hexa`. Team key: `HEX`. Issue IDs are `HEX-<n>`.
- States: Backlog -> Todo -> In Progress -> In Review -> Done.
- Type labels: `Feature`, `Bug`, `Improvement`.
